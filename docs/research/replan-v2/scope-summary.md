# v2 scope summary (feature matrix re-disposition)

Date: 2026-10-11. Source: `matrix.json` (263 catalog ids + 9 `NEW-` ids), generated by `tools/build_matrix.py`, which asserts every catalog id appears exactly once with a valid disposition and phase.

## Phase structure used

The default structure, unchanged:

| Phase | Scope |
|---|---|
| **P0 Foundations** | Repo, CI, app skeleton, theme, navigation shell, feed fetch/cache/parse core with tests, early spikes |
| **P1 Attendee core** | Schedule, session detail, My schedule, search and filter, Now, speakers, rooms list and detail, tracks and events |
| **P2 Conference companion** | Maps and floor plans, expo, sponsors, info pages, Welcome, Settings, local reminders, calendar, change log, deep links, HC themes |
| **P3 Account & staff on the mock** | Mock server, sign-in, favourites sync, role flags, the four staff tools, offline outbox |
| **P4 Showcase** | Performance, accessibility audit, docs, talk material |

Fable proposed a separate "native upgrades" phase. I did not adopt it. Upstream Flet work (E1, E3, U1, U4, U15...) runs as a **parallel track** of `upstream` issues:
- Each gap ships its interim in the phase that needs it.
- Spikes start early: E3/S6 during P1–P2, E1/S5 at the start of P3.
- An interim upgrades only after a tested Flet pin bump, not when an upstream issue closes (Codex).

P4 is mostly exit-criteria work, not features, so only one matrix row (NEW-09) lands there.

Conventions in the matrix:
- **phase `none`:** used for drops only.
- **disposition `new`:** used for NEW rows; the brief's vocabulary covers existing ids only.
- **Combined dispositions** like `improve+mock` are allowed. The first tag is the primary one.

## Drops (23) and why

- **Appflow OTA (LIVE-01..04, NOTIF-12):** `flet build` bundles Python in the binary, and App Store rule 2.5.2 forbids downloaded interpreted code.
- **Push and analytics (NOTIF-04, NOTIF-08, NOTIF-09, NOTIF-11, NATIVE-04, NATIVE-05):** there is no PSF Firebase sender, and the brief rules out analytics (B6, B7). `flet-firebase` stays a low-priority upstream item.
- **Web, PWA and PSF-only items (NATIVE-09, NATIVE-07, NATIVE-10, THEME-07):**
  - NATIVE-09: no web target.
  - NATIVE-07: shared credentials need the PSF domain.
  - NATIVE-10: a new app id starts from a clean slate.
  - THEME-07: the skip link is web-only.
- **Subsumed by better designs (SCHED-06, SCHED-23, SCHED-11, SCHED-28, NOTIF-02):**
  - SCHED-06 and SCHED-23: global search covers all days and all tracks.
  - SCHED-11: swipe-to-favourite is replaced by a visible, labelled star.
  - SCHED-28: blocking loaders give way to skeletons and a status strip.
  - NOTIF-02: a master toggle over 3–4 rows only adds a mixed state.
- **Developer leftovers (DEV-02, DEV-07, DATA-27):**
  - DEV-02: a console dump is useless on a phone; "Share log" replaces it.
  - DEV-07: three build flavours become one build plus runtime developer settings.
  - DATA-27: dead feed branch; we only log a warning.

## Notable redesigns (what changes)

- **Navigation (SHELL-04/05/09/10/16, SESS-12):**
  - The bottom bar has five fixed destinations, the same for every user, and there is no drawer. More is a flat sectioned list.
  - A recursive drill route makes Back pop one hop everywhere (#279).
  - Android Back on a non-start root goes to the start destination.
  - iOS edge-swipe and Android predictive back are kept.
- **Staff entry (SHELL-06/07/11, AUTH-05/06):** no role-dependent Scanner tab and no sheet. Staff use a More › Staff tools section and a Now card, driven by the pure `staff_entries(flags)`.
- **Sponsor chrome (SHELL-08, SPON-11):** the 30 s rotating strip on every screen goes (WCAG 2.2.2, #311 crowding). It is replaced by:
  - a Now spotlight;
  - a non-auto-advancing carousel;
  - contextual credits.
- **Theme (THEME-01/02/03/10, STORE-08):**
  - M3 seeded from `#3B3EA9` with brand overrides, identical on both platforms.
  - Theme follows the system by default, with high contrast as a separate switch.
  - Ionic blue and the iOS `#000` dark surfaces are gone.
- **Schedule (SCHED-01/02/09/10/17/21, DATA-18/29):**
  - Day tabs show dates.
  - A time-gutter slot layout stands in for the missing sticky headers.
  - Filters move to a live chip sheet, and the default exclusion is visible.
  - Queries are immutable, so filters no longer leak between screens.
  - A tracks hub merges the Session Types legend, with clean slugs.
- **Now (SCHED-25):**
  - Uses the real end-time check (Ionic kept the last slot "now" until midnight).
  - Adds a "Your next session" card, progress bars, and pre/post-conference states.
  - Back returns to Now.
- **Session detail (SESS-01):** a "When and where" card comes first, plus a not-found state and a removed-from-feed banner.
- **Content as data (DATA-34, SESS-08, SPKR-04, INFO-07/09, MAP-09/10, EXPO-02):** year facts move to bundled `data/<year>/*.toml`: Wi-Fi, CoC contacts, keynotes, hours, booth geometry, sponsor credits. This removes Ionic's `'temporal'` and `'google'` substring hacks. Help & safety merges CoC and Help.
- **Settings and reminders (NOTIF-01/03/06, STORE-10):**
  - Only working options are shown.
  - Permission is asked in context after a primer, never at boot.
- **Mock-backed staff (MASK-04, LEAD-13/14, API-04):**
  - CoC scans open a review dialog instead of recording once per frame.
  - A sync chip and queue sheet add retry.
  - Favourites sync is local-first, and a server `[]` never wipes local data.

## Data-semantics invariants kept (`keep` rows plus notes)

- **processData rules (DATA-04..11, SCHED-19):** each rule gets a named test on the 2025/2026 fixtures. Ionic outputs are captured once as reference fixtures, with no Node in CI. The rules:
  - placeholder filtering exempts poster and break;
  - open spaces get `+9000` ids;
  - `poster-detail-*` sessions;
  - the collapse keys;
  - Lunch spans;
  - the Job Fair label shifted −30 min;
  - pre-registration and Spanish flags.
- **Ids:** string ids in four forms, stable across reloads, quoted in routes (DATA-26).
- **Speakers:** linked by name; pseudo-speakers are excluded (DATA-15).
- **Slugs:** three distinct slug functions kept exactly (SPON-02, ROOM-06, MAP-07).
- **Time:**
  - conference-TZ labels through `zoneinfo` + `tzdata`;
  - one `clock.now()` and one `today()`;
  - every time group has a start time (DATA-12/13).
- **Cache:** replaced only after a good parse, in persistent storage, never wiped by a refresh (DATA-02/03, STORE-01).
- **Signing:** byte-exact, plus a test vector produced by Ionic's own code (API-01).
- **Outbox:**
  - sponsor snapshot per row;
  - one row per door check-in;
  - network errors never count toward the retry cap;
  - synced rows kept (API-10, STORE-11/12).
- **Endpoint guard:** the client refuses `/api/v1` on `*.pycon.org` (API-12).

## Open decisions surfaced by the matrix (for U)

1. **Bottom-bar destinations.** Proposal: Now · Schedule · My schedule · Map · More. The studies disagree on whether Speakers or My schedule gets a tab.
2. **Start destination.** Now or Schedule.
3. **Page transitions.** Per-platform transitions (iOS swipe, Android predictive) as the one allowed platform difference.
4. **Search word semantics.** AND, proposed, versus Ionic's OR.
5. **Order inside a time slot.** Start then room, or track then title.
6. **Speaker sort.** Displayed name or family name.
7. **Track badge style.** Saturated fills or tonal pairs; both pass AA.
8. **Sponsor visibility.** Is spotlight plus carousel enough without the strip?
9. **Staff landing.** Lead-scanner landing as a switchable default (#310).
10. **Expo zoom-to-booth.** Deferral until U3 (EXPO-05 `later`).
11. **High contrast.** Keep HC only if it fits Material `ColorScheme` cleanly.
12. **Identity.** Bundle id, a trademark-safe display name and artwork before anything leaves our devices.
13. **Staff-tool behaviour (P3).** Show attendee names at the door? Pre-check swag items? Hide CoC emails until revealed?
