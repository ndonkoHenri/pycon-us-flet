# Decisions record: PyCon US 2027 app on Flet

**Status:** authoritative as of 2026-10-11 (amended the same day by section P, D-108..D-136). Plan of record: [`PLAN.md`](../PLAN.md). Feature table: [`feature-matrix.md`](feature-matrix.md). PyCon US 2027 is May 12-18, 2027 in Long Beach, CA (confirmed: PyCon US blog, 2026-09-24); only the per-day split is UNCONFIRMED (D-135).

**Rules for later writers.** This applies to anyone writing `docs/architecture.md`, `docs/flet-gaps-and-extensions.md`, `docs/build-and-release.md`, `docs/backlog.md` or `docs/testing-and-quality.md`.
- These decisions are binding.
- If a doc needs a different choice, amend this record first. Add a new D-number and mark the old one "superseded by D-xx". Then update PLAN.md.
- Decisions marked **provisional (OD-n)** follow the recommendation in PLAN §13 until the user or the PSF decides otherwise.
- `docs/feature-matrix.md` is the source of truth for dispositions. Edit it directly, then re-check coverage with a script against the 263 ids (every id exactly once; the check snippet in `docs/backlog.md` §14 does this). The generator scripts used to build the first version are retired and must not be used.

## D. Routing and navigation

| # | Decision | Rationale |
|---|---|---|
| D-30 | *(amended by D-121)* `page.render_views(App)` with `ft.Router(ROUTES, not_found=NotFound, manage_views=True)`. | Flet's intended declarative style. |
| D-31 | Ionic URL paths are kept 1:1 under the componentless group `app/tabs`. This includes the slugs `ais`, `securitys`, `lightning-talkss`, `open-spaces`; the route `notifications`; and `lead-retrieval` = Lead Scanner. Unknown paths go to `NotFound`. | Web URLs and deep links address the same screens as Ionic. |
| D-32 | **No outlet layout.**<br>• Every view-level screen returns its own `ft.View` through a shared `shell_view(...)` with `route=ft.use_view_path()`.<br>• `leading=MenuButton()` only on stack roots; detail screens get `leading=None` and the implicit back arrow.<br>• Wide screens (>= 992 px) render a permanent 304 px drawer column instead of `View.drawer`. | Prevents a View nesting inside a View and keeps titles and actions per screen. |
| D-33 | Redirect components (`IndexRedirect`, `ShortLink`, `Guard`) return a **minimal boot View** and call `page.navigate()` in a mount effect. | View-level routes must return Views. |
| D-34 | **Recursive drill segment** `ft.Route(path=":ref", recursive=True, component=Drill)` is a child of every session, speaker and room detail route.<br>• Refs: `s~<urlencoded session id>`, `p~<speaker id>`, `r~<room slug>` (plus `?session=` for highlights).<br>• `Drill` dispatches on the prefix; one View per hop.<br>• Session routes are generated by a helper, never copy-pasted. | Real back stack for cross-links (#279). |
| D-35 | *(amended by D-123)* The floor plan is a **global modal** `/floor-plan/:plan?pin=<room_key>` declared at the **top level**. Filter (`schedule/filter`), lead note (`lead-retrieval/note/:code`) and swag redeem (`t-shirt-redemption/redeem`) are **local modals**. Modal components return `View(fullscreen_dialog=True)`. | Top-level declaration means the base stack is rebuilt from the last non-modal location. |
| D-36 | Drawer destinations replace the stack (`page.navigate(root)`), so Back on a root exits. The system navigation bar is never hidden (#311). | Matches Ionic `routerDirection=root`. |
| D-37 | Query strings come from a `use_query()` helper that calls `ft.use_route_location()` and parses `page.route`. It is replaced by U9 `use_route_search()` when that lands. Spike **S9** verifies that `page.route` carries the query. | No search hook exists today. |
| D-38 | *(config clause superseded by D-109)* Deep links: `[tool.flet.deep_linking] scheme="pyconus" host="app"`. Short aliases `/s/:id`, `/p/:id`, `/r/:slug` redirect to the canonical routes. No universal links in 27.0. | Custom-scheme deep linking already exists in `flet build`. |
| D-39 | The active tab comes from the first segment after `/app/tabs/`, read through **one** `use_route_location()` call. Map is lit only on `conference-map`, not `expo-hall`. Scanner is lit only on `lead-retrieval`. When no tab matches, render a transparent indicator with unselected styling, because `NavigationBar.selected_index` is an `int`. | Ionic parity. |
| D-40 | *(amended by D-123)* Route guards:<br>• `lead-retrieval`: `lead_retrieval or door_check`<br>• `door-check`, `t-shirt-redemption`: `door_check`<br>• `mask-violation`: `mask_violation`<br>• `account`: logged in<br>• `dev-tools`: `settings.DEV` or 7-tap unlock<br>A failed guard renders a "Not available for this account" View. | Web and deep links can reach staff URLs. |
| D-41 | **Staff gating truth table** (Ionic exact; unit test `test_AUTH_05_gating_truth_table`):<br>• Scanner tab opens the sheet when `door_check or mask_violation`.<br>• Scanner tab is a plain tab when `lead_retrieval and not door_check and not mask_violation`.<br>• Door Check and Swag items: `door_check`.<br>• Lead Scanner item: `lead_retrieval or door_check`.<br>• CoC item: `mask_violation`.<br>• `is_staff_scanner = door_check and not lead_retrieval`.<br>• Login tab: not logged in. | Two of the three drafts got a gate wrong. |
| D-42 | Launch and post-login redirect to Lead Scanner **only when `lead_retrieval`**. Door-check-only staff land on Schedule. The redirect runs after `await auth.restore()`. | Ionic parity; no stale flags. |
| D-43 | Chrome:<br>• The sponsor strip and the `NavigationBar(adaptive=True)` sit in a `Column` inside `View.bottom_appbar`, with an explicit `BottomAppBar.height`.<br>• The drawer is `View.drawer=ft.NavigationDrawer(...)`, opened and closed only from `async def` handlers that `await page.show_drawer()/close_drawer()`.<br>• `is_route_active` is never called inside role-conditional sections; use prefix checks on one `use_route_location()`. | A View renders either `navigation_bar` or `bottom_appbar`, not both. `is_route_active` is a hook. Async APIs need async handlers. |

## E. State, data, API, storage

| # | Decision | Rationale |
|---|---|---|
| D-44 | All shared state lives in `@ft.observable` dataclass stores: `FeedStore`, `AppConfigStore`, `ContentStore`, `AuthStore`, `Features`, `Prefs`, `Favorites`, `StaffStore`, `OutboxStore`, `BannerStore`, `ChangeLog`, `Caps`. They are created **once** in `App` via `ft.use_memo(lambda: Stores.create(ft.context.page), [])`. | Services register with the page. |
| D-45 | **One context per store** (`ft.create_context` each), exposed through typed hooks `use_feed()`, `use_app_config()`, `use_content()`, `use_auth()`, `use_features()`, `use_prefs()`, `use_favorites()`, `use_staff()`, `use_outbox()`, `use_banners()`, `use_changelog()`, `use_caps()`. **Never** put a container of stores in one context. | `use_context` subscribes only when the value is an Observable; nested observables do not propagate. |
| D-46 | *(amended by D-122)* Bootstrap is `ft.use_effect(stores.bootstrap, [])` with an **async bound method**. Never pass a lambda that returns a coroutine.<br>Order:<br>1. prefs (theme and filters before first themed render)<br>2. optional bridge import<br>3. `await auth.restore()`<br>4. publish the cached feed<br>5. network refresh<br>6. `check_features` and `mobile_state`, once<br>7. app-config and app-content<br>8. `SyncWorker.start()` and the banner task | The effect runner only creates tasks for coroutine functions. |
| D-47 | Derived data uses `ft.use_memo` keyed on `(feed.version, ...)`, with `tuple(...)` for list dependencies. `Favorites.ids` is a `list[str]`, never a `set`. View models are fresh objects; shared data is never mutated in place. | Observables wrap lists and dicts; this also fixes Ionic's cross-page flag leaks. |
| D-48 | `src/pycon_us/core/` must not import `flet` (lint). It holds parse/process, queries, timefmt, slugs, html_md, ics, badges, signing, admission, the outbox state machine, the changelog and models. | D-50 | *(synthetic-id wording superseded by D-115)* **Processing parity.**<br>• All ids are `str`; synthetic ids stay unchanged (`conf_key+9000`, `poster-detail-<k>`, `kind-day-name[-start]`).<br>• Named tests cover: the placeholder filter **exempts poster/break**; generic Break rows display no location; Lunch spans earliest → latest; Job Fair is grouped at 10:00 and labelled 9:30; speakers link by name; 16 sprint rooms are seeded; `TimeGroup.start_time` is always set.<br>• A bad slot is skipped and reported.<br>• Proof: a differential harness (D-96). | Data semantics are the product. |

## N. Corrections that later docs must honour (verified in the local SDK on 2026-10-11)

1. `page.show_drawer`/`close_drawer`, `page.push_route`, `ListView.scroll_to`, `InteractiveViewer.zoom/pan/reset`, `Clipboard.set`, `Dismissible.confirm_dismiss`, `SharedPreferences.*`, `UrlLauncher.launch_url`, `Share.share_files`, `SemanticsService.announce_message` and `SemanticsService.get_accessibility_features` are **coroutines**. Call them from `async def` handlers or effects. `page.navigate(route, **query)` and `page.show_dialog` are sync.
2. `ft.use_effect(setup)` creates a task only when `setup` is a coroutine function. A lambda that returns a coroutine never runs.
3. `ft.use_context` subscribes only when the provided value is an `Observable`. Nested observables do not propagate.
4. Handler and sync-effect exceptions call `session.error()`, which sends `SESSION_CRASHED`. Async effect task exceptions reach only asyncio. `page.on_error` is Flutter-side.
5. `scroll_to(scroll_key=...)` does nothing when the keyed control is not built (lazy `ListView`).
6. `is_route_active` is a hook (`use_context`). `use_route_location()` returns the pathname only. There is no `use_route_search`. `LocationInfo.search` exists internally.
7. A top-level `modal=True` route is global (base = last non-modal location). A modal under a parent is local (base = the parent chain). A componentless group emits no View.
8. These do **not** exist: `ft.RefreshIndicator`, `InteractiveViewer.set_transform`, `AppBar.bottom`, `Page.get_app_info`, any sticky header. `IconButton.badge` is `str | Badge`, not a component. `NavigationBar.selected_index` is an `int`.
9. Deep linking (custom scheme) **is** supported by `flet build`. Universal links and App Links `autoVerify` are not.
10. `importlib.metadata.version("pycon_us")` does not work in a packaged app; use `build_info.py`.
11. permission_handler has no iOS notification macro; request notification permission through the notification plugin. The correct key spelling is `NSCalendarsWriteOnlyAccessUsageDescription`.
12. `BottomSheet` has no detents. `SnackBar` is bottom-only. `ft.Banner` is a `DialogControl`.
13. `SharedPreferences` accepts only `str/int/float/bool/list[str]`. `StoragePaths` raises on web. httpx is not installed under Emscripten.
14. `SemanticsService().get_accessibility_features()` exposes `reduce_motion`, `disable_animations`, `high_contrast`, `bold_text`, `supports_announcements` and more. `reduce_motion` is reported only on iOS; on Android below API 34, `high_contrast` is always False (D-118, D-119).
15. *(added by D-122)* On unmount, an async effect task is cancelled only when a callable `cleanup` is passed. Long-running async effects pass `cleanup=NOOP`; `App` passes `cleanup=s.shutdown`.
16. *(added by D-122)* Assigning an observable field runs `old == new` before notifying. Large store values (the processed feed, app-content) are `@dataclass(frozen=True, eq=False)` containers with id references and no object cycles; otherwise speaker↔session cycles make the compare slow or recurse.
17. *(added by D-121)* With `manage_views=True` the Router wraps `not_found()` in a `View` itself (`components/router.py`), so `NotFound` returns plain content.
18. *(added by D-118, D-120)* `Banner` and `CupertinoBottomSheet` are `DialogControl`s; `CupertinoActionSheet` is not. `Banner` needs at least one visible action and has no `duration`.
19. *(added by D-109)* For `aab`/`apk` and `ipa` builds flet-cli reads only `[tool.flet.android.deep_linking]` / `[tool.flet.ios.deep_linking]` (`build_base.py` ~1421-1438); the global `[tool.flet.deep_linking]` is used only for other targets.
20. *(added by D-129)* The on-device `RemoteTester` has `tap` and `long_press` but no `drag`, `drag_from` or `tap_at`; swipe gestures are testable in host mode only.
21. *(added by D-134)* `flet run` watches only the entry script unless `-r`/`--recursive` is passed; hot reload restarts the Python process, so app state resets.
